# PawPaa Hospital ERP

Animal Hospital ERP for OPD, IPD, ambulance/field treatment, pharmacy, inventory, billing and management operations.

## Development
This repository contains the source code for the PawPaa Hospital ERP.

## Local environment
- Laravel
- PHP
- MySQL / MariaDB
- Blade
- Bootstrap
- Vite

> Environment secrets and local configuration must never be committed to Git.
